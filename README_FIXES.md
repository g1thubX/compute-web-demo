# 问题修复总结

## 本次修复的所有问题

### 问题 1: WalletConnect 连接错误
**错误**: `Connection interrupted while trying to subscribe`
**修复**:
- 禁用 reactStrictMode (防止双挂载)
- 配置有效的 projectId
- 添加全局错误处理
- 创建 pages/_document.tsx

### 问题 2: 账户初始化失败
**错误**: `missing revert data`
**修复**:
- 添加转账错误捕获
- 转账后重新获取账户
- 防御性的 null/undefined 检查

### 问题 3: 响应解析错误
**错误**: `Cannot read properties of undefined (reading '0')`
**修复**:
- 检查 HTTP 状态
- 验证响应结构
- 深层嵌套检查

### 问题 4: 请求格式错误
**错误**: `API request failed with status 400`
**修复**:
- 验证 metadata 和 headers
- 正确处理 endpoint URL
- 详细的错误日志
- 增强的错误响应解析

### 问题 5: 余额不足 ⭐ **最新**
**错误**: `insufficient balance, total fee of 400003600000000000 exceeds available balance of 0`

**含义**: 需要 0.4 个 token，但账户余额为 0

**解决方案 (3 步)**:

1. **打开"账户"标签**
   - 在应用界面点击"账户"按钮

2. **充值账户**
   - 输入金额（推荐 1-2）
   - 点击"充值"按钮
   - 等待完成

3. **返回聊天重试**
   - 回到"聊天"标签
   - 发送消息
   - AI 应该正常回复
